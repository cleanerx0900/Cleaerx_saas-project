# CleanerX SaaS - Module 1 (Database Setup)

1. Supabase par project banao.
2. Tables create karo: Users, Companies, Subscriptions, Services, Bookings, Payments, Notifications.
3. `supabaseClient.js` mein apna Supabase URL aur API key paste karo.
4. Replit par upload karo aur `npm install` run karo.
5. `npm start` run karke test karo.
